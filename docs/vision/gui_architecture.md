## Модули

| Модуль | Назначение |
|---|---|
| vision_window.py | вкладки, действия оператора, импорт, история, контроллер видео |
| board_calibrator.py / EmbeddedCalibrator | прежний редактор с прежним Document и схемой карты v1 |
| result_pane.py | восстановление отчёта, ленивые слои, выбор ROI в таблице/изображении |
| jobs.py | QRunnable, QObject-сигналы, threading.Event отмены |
| research_project.py | переносимый проект JSON, роли, проверка карты, batch, уникальные каталоги |
| video_source.py | один VideoCapture, seek, один кадр/metadata, явное release |
| optical_signal.py | новый цветовой классификатор по приросту, confidence/reason |
| led_detection.py | прежний pipeline с параметрами регистрации/цвета и точками отмены |

В Qt pool один рабочий поток: декодирование видео, импорт и анализ
не исполняются одновременно. Сигналы доставляются методам GUI-потока;
рабочий код не обращается к виджетам. Изменение карты и конкурирующие
операции во время задания блокируются. Повторные запросы слоя/seek
объединяются: после текущего задания обслуживается последний запрос.
Память освобождается между изображениями batch; просмотрщик держит только
выбранный слой. Миниатюры JPEG используют draft-декодирование Pillow.

Отмена кооперативная: между файлами и этапами чтения/регистрации/детекции.
Нельзя безопасно оборвать отдельный вызов OpenCV/кодека посередине.
Закрытие занятого окна запрашивает отмену и предлагает дождаться окончания,
не уничтожает работающий Qt-поток. VideoCapture закрывается при смене
видео/проекта и при закрытии приложения. Проект атомарно сохраняется
через прежний atomic_json. При аварийном завершении GUI уже записанные
отчёты остаются на диске; незавершённая история не восстанавливается
автоматически — это оставшееся ограничение.

## Данные и совместимость

Карта калибровки остаётся schema_version=1. Новый проект — отдельный
application="GS75 RGB Vision", schema_version=1. data_root определяет корень
прежних относительных путей карты; пути медиа/отчётов относительны к JSON
проекта, разные диски допускают явную абсолютную ссылку. Импорт медиа
не меняет исходники; автоматически создаются только thumbnails/captures.

Batch сохраняет точную карту в calibration_snapshot.json, настройки и версию,
отдельные отчёты и общий CSV/JSON. UUID исключают молчаливую перезапись.
Каждый OFF/ON заново регистрируется. CLI сохранены; GUI использует тот же
analyze_paths. Исходные числа сохраняются в английских JSON-полях.

Цвет v0.3 оценивается по компенсированному приросту, с вычитанием нейтральной
составляющей каждого пикселя. secondary/primary ≤0,45 — один канал;
≥0,70 — MIXED; промежуток — UNDEFINED/UNCERTAIN. Настройки доступны явно.
color_confidence — эвристический показатель разделения, **не вероятность**.
JSON содержит color_reason, color_evidence_rgb, secondary_primary_ratio.
Нулевой сигнал имеет confidence=0; клиппинг без ореола остаётся неопределённым.

## Проверка

Полный Python-набор включает старые тесты и новые project/video/GUI-тесты.
Проверяются роли, перенос JSON+данных, изменённая карта, недостающие файлы,
повторный batch без изменения входов, отмена с сохранением завершённых
результатов, Qt event loop, Drag & Drop, сохранение Advanced, история/слои,
MP4 seek/кадры/анализ/release, неизвестное время декодера.
Реальная приёмка: [v03_validation.md](v03_validation.md).
Тесты личных фото явно skip, если данных нет; синтетика не выдаётся за них.
