# Распиновка

| Сигнал | GPIO | U21 LQFP64 |
|---|---|---|
| SRC_CH0/1/2 | PA4/PA5/PA6 | 20/21/22 |
| SRC_BANK0/1/2 | PA7/PA8/PA9 | 23/41/42 |
| SRC_BANK_EN | PA10 | 43 |
| SNK_CH0/1/2 | PC6/PC7/PC8 | 37/38/39 |
| SNK_BANK0/1/2 | PC9/PC10/PC11 | 40/51/52 |
| SNK_BANK_EN | PC12 | 53 |
| ADC_SENSE | PA0 | 14 |
| USB D−/D+ | PA11/PA12 | 44/45 |
| SWDIO/SWCLK | PA13/PA14 | 46/49 |

PB6/PB7 UART и PB3 SWO в этой прошивке не используются. PB2 boot1 не трогается.
PA9 и PA10 остаются GPIO: USB VBUS sensing и OTG ID отключены.

| KP/FPC | SOURCE | SINK | BANK | CH |
|---|---|---|---|---|
| 1–8 | U1 | U6 | 4 | 0–7 |
| 9–16 | U2 | U7 | 3 | 0–7 |
| 17–24 | U3 | U8 | 2 | 0–7 |
| 25–32 | U4 | U9 | 1 | 0–7 |
| 33–40 | U5 | U10 | 0 | 0–7 |

Для каждого диапазона каналы идут последовательно. Например, 1→4/0,
8→4/7, 9→3/0, 16→3/7, 17→2/0, 24→2/7, 25→1/0,
32→1/7, 33→0/0, 40→0/7.
Физические выводы 4051 Y0…Y7: 13,14,15,12,1,5,2,4.
Дешифратор Y4…Y0: 11,12,13,14,15.

В исходной схеме FPC1 pin N соединён с KP N для N=1…40; 41/42 — GND.
Направление счёта на изготовленном разъёме и реальном шлейфе определить
по документации разъёма и прозвонкой, затем записать фото/схему ориентации.
Host-тест 1560 пар проверяет адресацию, электрическое сканирование не выполняет.
