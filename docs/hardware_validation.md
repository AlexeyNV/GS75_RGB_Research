# Протокол аппаратных испытаний FW 0.1.1

Результаты предоставлены оператором и получены на физическом стенде,
отдельно от host-тестов. Первоначальный протокол сохранён 15 ноября
2026 года; дата выполнения первоначальных испытаний в сообщении не указана.
16 ноября 2026 года добавлены результаты прерывания импульса командой OFF
из раздела 5a PROJECT_CONTEXT.md и исходные JSON-протоколы этих опытов.

## Условия

* Прошивка **FW 0.1.1** фактически записана через **USB DFU**.
* Контрольная нагрузка — резистор **1 кОм между KP27 и KP35**.
* Перемычка **U13 разомкнута**.
* Оригинальная RGB-плата MSI в этих испытаниях не проверялась.

Для первоначальных испытаний ниже приведены поля и результаты из сообщения
оператора; полные логи терминала и осциллограммы к ним не приложены.
Для OFF-теста сохранены исходные JSON с событиями TX/RX, см. отдельный
раздел ниже. Осциллограммы OFF не снимались.

## Связь и измерения без нагрузки

Подтверждена работа USB CDC и команд PING, INFO, STATUS.

| Проверка | Фактический результат |
|---|---|
| ADCSTATUS | SAMPLES=146796, VALID_SAMPLES=146796, ERRORS=0, OVR_COUNT=0, AGE_MS=0, VALID=1 |
| CURRENT без нагрузки | RAW=2, CURRENT_UA=16, VALID=1 |
| SELFTEST | SELFTEST=PASS |

В полученном снимке все 146796 измерений допустимы, зарегистрированных
ошибок сбора и overrun нет, данные свежие. Показание 16 мкА без нагрузки
зафиксировано как результат измерения, а не подтверждение точности или
калибровка нуля.

## Импульсы на контрольной нагрузке

SOURCE — первый аргумент PAIR, SINK — второй. В обоих направлениях
использована длительность 300 мс и одна и та же нагрузка KP27–KP35.

| Команда | Средний ток, опыт 1 | Средний ток, опыт 2 |
|---|---:|---:|
| PAIR 35 27 300 | 1249 мкА | 1253 мкА |
| PAIR 27 35 300 | 1254 мкА | 1254 мкА |

В каждом из четырёх испытаний получено **299–300 отсчётов**,
**FAULT=NONE**, **REASON=TIMEOUT**.

После испытаний STATUS показал:

```text
STATE=IDLE SRC_EN=0 SNK_EN=0
```

Таким образом, после завершения импульсов прошивка сообщала отключённые
разрешения обоих банков. Осциллографическое измерение момента отключения
этими данными не подтверждено.

## Подтверждённый объём

* Запись FW 0.1.1 через USB DFU и обмен через USB CDC.
* Работа ADC после исправления, свежие допустимые данные и SELFTEST=PASS.
* Сбор 299–300 отсчётов за исследованные импульсы 300 мс.
* Коммутация SOURCE KP35 → SINK KP27 и SOURCE KP27 → SINK KP35
  на контрольном резисторе 1 кОм при разомкнутой U13.
* Завершение этих импульсов с причиной TIMEOUT и отключёнными EN в STATUS.
* Прерывание активного PAIR командой OFF в двух опытах с запрошенными
  задержками 50 и 100 мс после ACK; подтверждения по USB CDC приведены ниже.

Результаты не распространяются на все 40 физических контактов, все 1560
направленных пар, точность измерения тока или поведение оригинальной
RGB-платы. Программные тесты адресации всех пар остаются отдельным видом
проверки и не заменяют физическую проверку каналов.

## Эксперимент №2: прерывание PAIR командой OFF — 16.11.2026

Условия: FW 0.1.1, оригинальная RGB-плата MSI отключена, U13 разомкнута,
резистор 1 кОм между KP27 и KP35; Windows, USB CDC COM19.
Оператор использовал [tools/test_off.py](../tools/test_off.py).

| Показатель | Задержка 50 мс после ACK | Задержка 100 мс после ACK |
|---|---|---|
| Команда | PAIR 27 35 300 | PAIR 27 35 300 |
| ACK ID | 1 | 2 |
| TX OFF, мс с начала записи | 157 | 188 |
| RX DONE, мс с начала записи | 172 | 219 |
| CURRENT_AVG_UA | 1254 | 1254 |
| CURRENT_MAX_UA | 1265 | 1281 |
| SAMPLES | 67 | 115 |
| DONE STATE | OFF | OFF |
| DONE REASON | OFF | OFF |
| DONE FAULT | NONE | NONE |
| Последующий STATUS | DISARMED, SRC_EN=0, SNK_EN=0, FAULT=NONE | DISARMED, SRC_EN=0, SNK_EN=0, FAULT=NONE |
| Результат скрипта | PASS_PROTOCOL | PASS_PROTOCOL |

До импульсов в обоих опытах ADCSTATUS показал VALID=1, ERRORS=0,
OVR_COUNT=0; SELFTEST=PASS. После OFF получены DONE с соответствующим
ACK ID и ответ `OK DISARMED`. Скрипт сообщил в обоих случаях:

```text
PASS: OFF ended the pulse; firmware reported both BANK_EN disabled.
```

Исходные протоколы сохранены без изменения:

* [off_test_50ms.json](../results/off_test_50ms.json), timestamp_utc
  `2026-11-16T07:23:04.360864+00:00`.
* [off_test_100ms.json](../results/off_test_100ms.json), timestamp_utc
  `2026-11-16T07:23:11.732649+00:00`.

50 и 100 мс — запрошенные задержки скрипта после получения ACK.
Метки TX/RX относятся к записи на Windows. Интервалы от TX OFF до RX DONE
составили 15 и 31 мс; они включают USB/host latency и не являются временем
физического выключения ключей. 67/115 отсчётов вместо 299–300 в полном
импульсе согласуются с его прерыванием.

**Вывод:** OFF прерывает активный PAIR на исследованной контрольной нагрузке,
а прошивка сообщает об отключении обеих групп и состоянии DISARMED.
Оба опыта прошли без FAULT. Реальные фронты BANK_EN, задержка физического
отключения и поведение при Reset/авариях осциллографом не проверены.
Повторять тот же USB-протокольный тест без новой причины не требуется.

Скрипт и эти два JSON включаются в Git как материалы испытаний.
Текущий `.gitignore` их не исключает; `__pycache__/` и `*.pyc` остаются
исключёнными. В Git сохраняются только выбранные протоколы, а не весь
каталог результатов или временные файлы.

## Непроверенное и следующий этап

USB-протокольная проверка OFF завершена. Непроверенными остаются
физические фронты и время отключения BANK_EN при OFF/Reset/авариях,
остальные каналы, точность измерения тока и подключение оригинальной
RGB-платы MSI. Подтверждение состояния по USB CDC не заменяет измерение
физического сигнала осциллографом.

Следующие работы, в указанном порядке:

1. Пассивно исследовать электрическую схему оригинальной RGB-платы MSI
   GS75 без питания: фотографии обеих сторон и разъёма, ориентация FPC,
   трассировка общих цепей, LED, резисторов и возможных активных элементов.
2. Уточнить точки и способ предварительных измерений сопротивлений из
   раздела 6 PROJECT_CONTEXT.md. Не считать их доказательством полярности
   всех LED или назначения всех контактов.
3. Только после пассивной проверки схемы подготовить безопасное первое
   подключение оригинальной RGB-платы MSI. Само подключение ещё не выполнено.

Осциллографическая проверка EN и независимая проверка точности ADC остаются
отдельными открытыми аппаратными проверками.

Пределы и защитные механизмы прошивки не изменяются: ADC_STALE_MS=5 мс,
нет автоматического включения выходов, для импульсов требуется явный ARM.
