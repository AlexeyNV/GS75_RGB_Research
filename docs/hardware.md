# Аппаратная проверка схемы

Источник: `hardware/easyeda/SCH_PCB_light_keyboard_2026-11-09.json`, лист Sheet_1.
`tools/check_schematic.py` извлекает выводы символов, провода, junction и
одноимённые net labels. Результат — `schematic_nets.json`. Скрипт учитывает
соединение вывода с серединой провода; простое пересечение без junction не
создаёт соединения. Это проверка исходного документа, а не прозвонка PCB.

Подтверждены все 40 каналов обеих групп, GPIO, U11/U12, R1/R2/R3, R16/R17,
кварц U22. В схеме нет расхождений с заданной картой коммутации.

| Цепь | Соединение |
|---|---|
| SOURCE | USB_+5V → R1 2,7 кОм → SRC_BUS → U1…U5 Z |
| SINK | U6…U10 Z → SINK_BUS → R2 100 Ом → GND |
| ADC | SINK_BUS → R3 1 кОм → ADC_SENSE → PA0; C15 10 нФ на землю |
| Дополнительный ток | USB_+5V → U13 → R18 1,5 кОм → SRC_BUS; U13 разомкнуть |
| Дешифраторы | U11/U12 E1/E2=GND, E3=BANK_EN; инверсные Y4…Y0 → E мультиплексоров |
| Состояние Reset | R16/R17 10 кОм от BANK_EN к GND; адреса R4…R15 100 кОм к GND |
| Питание | USB VBUS → F1 MF-PSMF050X-2 → USB_+5V; U23 TLV1117LV33 формирует VDD |
| Аналоговое питание | VDD → U29 BLM18PG471SH1D → VDDA/VREF+; VSSA/VREF−=GND |
| USB | PA11 → R37 22 Ом → D−; PA12 → R36 22 Ом → D+; защита D6 USBLC6-2SC6 → USBC |

HCT4051/HCT138 имеют TTL-совместимые цифровые входы при 5 В; STM32 управляет
ими логикой 3,3 В. Аналоговые сигналы коммутаторов не подключены напрямую к
GPIO управления. Банки отключены при BANK_EN=0, поскольку все выходы 138
высокие, а E 4051 запрещает канал при HIGH. Полярности проверены по
[74HCT138](https://assets.nexperia.com/documents/data-sheet/74HC_HCT138.pdf)
и [74HCT4051](https://assets.nexperia.com/documents/data-sheet/74HC_HCT4051.pdf).
Там же приведены времена переключения порядка десятков наносекунд при
4,5 В; выбраны две отдельные паузы по 10 мкс с запасом. Осциллографическая
проверка фронтов и реальной нагрузки остаётся обязательной.

При U13 open и USB=5,0 В верхняя оценка тока короткой нагрузки без учёта
сопротивления ключей — 5/(2700+100)=1,786 мА; при 5,25 В — 1,875 мА.
Порог 2 мА служит диагностикой, а не ограничителем тока. Сопротивление
открытых ключей и нагрузка дополнительно уменьшают ток.

Схема не доказывает, что изготовленная плата соответствует номиналам.
Проверить монтаж F1, ESD, VDDA, VCAP, NRST/BOOT0, кварца и развязки питания.
R3 не является ограничителем напряжения ADC при внешнем перенапряжении.
Нельзя подключать сторонние источники к FPC или питать RGB-плату независимо.
Ориентация реального FPC и расположение контактной стороны шлейфа ещё не установлены.
