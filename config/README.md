# Calibration maps / RGB Vision v0.2

A real LED49 map exists locally as config/gs75_board_calibration.json.
It is operator data and is not automatically tracked. Transfer it with
its reference photo, preserving relative paths and SHA-256. Never replace
real coordinates with synthetic examples. See PROJECT_CONTEXT.md.

Файл schema_version=1 содержит относительный путь эталонной фотографии,
SHA-256 её исходных байтов, исходные и EXIF-нормализованные размеры,
ориентацию, DICT_4X4_50, углы маркеров в порядке OpenCV, ожидаемые ID,
номинальные размеры наклеек, camera_model либо null, список LED и metadata.
calibration_version — версия содержимого; изменение карты создаёт новую.
LED ID уникален; key_name может быть null и повторяться у нескольких LED.
Координаты x_ref_px/y_ref_px сохраняются как float без округления в JSON.

Система reference_px: начало сверху слева, X вправо, Y вниз. EXIF-ориентация
применяется при чтении. При заданной camera_model координаты относятся к
изображению после undistort. Физические мм **не откалиброваны**.

Внешняя фотография импортируется копией в `data/reference/<sha256>.<ext>`;
оригинал не меняется. Изображения внутри проекта используются по относительному
пути. data/ и autosave исключены из Git, поэтому для переноса реальной карты
нужно отдельно перенести и фотографию с сохранением относительного пути.
Без неё или при другом checksum загрузка отклоняется. Большие пользовательские
снимки автоматически не публикуются. Выбранные небольшие материалы можно
добавлять в Git только адресно по решению оператора.

Опциональная camera_model задаётся до создания эталона кнопкой Camera Model:
поля `matrix` (3×3 K), `distortion` (4/5/8/12/14 коэффициентов OpenCV),
`image_size` ([ширина, высота] EXIF-нормализованного кадра). Это должны быть
известные параметры соответствующего объектива и разрешения, не оценки
по номинальному размеру наклейки. Все анализируемые изображения с такой
моделью должны иметь указанное разрешение. При отсутствии модели — null.
